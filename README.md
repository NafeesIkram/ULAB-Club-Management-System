# ULAB Club Management System

A Java Swing-based University Club Management System developed as a University Design Project.

This desktop application helps manage university club activities including members, events, notifications, and role-based access.

The project was successfully completed as a University Design Project and achieved an A Grade for its design, functionality, and implementation.

## Features

### Admin

- Manage users and members
- Approve membership requests
- Manage clubs and events
- Send notifications
- View system data

### President

- Manage club activities
- Add and update events
- View club members
- Send notifications

### Member

- View available clubs
- Join clubs
- View upcoming events
- Receive notifications

## How to Run

### Requirements

- Java JDK 17 or above
- NetBeans IDE

### Steps

1. Clone the repository

```
git clone https://github.com/NafeesIkram/ULAB-Club-Management-System.git
```

2. Open the project in NetBeans IDE.

3. Build the project.

4. Run the main class:


Designproject_1f.java
